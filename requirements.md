# Job Title: Create a website for “Restaurant” using HTML, CSS, JavaScript, and Bootstrap framework

## Conditions

1. Work must be carried out in a safe manner and according to coding standards
2. Open-source resources can be used
3. Written code must be clean & errors free

## Equipment: Personal computer /laptop, Internet

### Software: Web browser, IDE

### Requirements of website

1. 6 Page website
a. Homepage:
i. Header Top Section (Email, Phone Number, Reservation Link, Login,
Register).
ii. Navigation Section with Logo, Home, Menu, Reservation, About Us,
Contact, Login/Register links.
iii. Banner Section (Full width sliding images of food/dishes with call-to
action buttons like “Book a Table”).
iv. Special Dishes Section (Bootstrap cards with dish photo, description,
price, and “Order Now” button).
v. Chef’s Recommendation Section (Featured meals with images).
vi. Customer Testimonials Section (at least 2 reviews in Bootstrap cards).
vii. Newsletter Subscription Section.
viii. Big Footer Section (Restaurant info, quick links, timings, social
media).
ix. Footer Section (copyright).  
 b. Menu Page :  
 i. Breadcrumb Section.
ii. Food Categories Section (Accordion – Starters, Main Course, Desserts,
Drinks) – left panel.
iii. Menu Items Section (Bootstrap cards with food image, title, price, “Add
to Cart/Order” button) – right panel.
iv. Pagination for menu items.  
 c. Dish Detail Page :  
 i. Breadcrumb Section.
ii. Dish Image Zoom Section – left panel.
iii. Dish Information (title, price, ingredients, quantity selector, order now
button) – right panel.
iv. Dish Detail Section (full description, nutrition info).
v. Related Dishes Section.
d. Reservation Page :
i. Breadcrumb Section.
ii. Reservation Form Section (Name, Email, Phone, Number of Guests, Date,
Time, Special Request).
iii. Reservation Summary/Confirmation popup after form submission.  
 e. Signup Page:  
 i. Breadcrumb Section.
ii. Signup Form Section (First Name, Last Name, Phone, Email, Username,
Password).  
 f.
Login Page:
i. Breadcrumb Section.
ii. Login Form Section (Username, Password).  
2. Full container wide navigation menu with mouse hover effect.
3. Current Date & Time Using JavaScript
4. Include External CSS & JavaScript file
5. Internal Pages Linking
